# CodeAlpha AI Internship Projects

Three AI/ML projects completed as part of the CodeAlpha AI Internship.

## Projects

### 1. [Real-Time Object Detection & Tracking](./CodeAlpha_ObjectTracking)
Real-time object detection and tracking using Python, OpenCV, and YOLO.

**Tech:** Python, OpenCV, YOLO

### 2. [Intelligent FAQ Chatbot](./CodeAlpha_FAQChatbot)
A semantic-search FAQ chatbot using sentence embeddings and cosine similarity,
built with FastAPI.

**Tech:** Python, FastAPI, Sentence Transformers, Semantic Search

### 3. [AI-Powered Language Translation Tool](./CodeAlpha_LanguageTranslation)
A local, offline neural machine translation tool supporting English, Hindi,
Bengali, Tamil, Telugu, Marathi, and Gujarati - using Meta's NLLB-200
(distilled) model, with a live-translate web UI and translation history.

**Tech:** Python, FastAPI, Hugging Face Transformers, PyTorch, HTML/CSS/JS

## About

These projects were built to demonstrate practical, locally-runnable AI/NLP
applications - computer vision, semantic search, and machine translation -
without relying on paid third-party APIs.
